## 1. 无重复字符的最长子串（10 分）

### 题目描述

给定一个字符串 `s`，请你找出其中不含有重复字符的最长子串的长度。

### 示例 1

- 输入：`s = "abcabcbb"`
- 输出：`3`
- 解释：因为无重复字符的最长子串是 `"abc"`，所以其长度为 `3`。注意，`"bca"` 和 `"cab"` 也是正确答案。

### 参考实现

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        if (s.empty()) {
            return 0;
        }

        int ans = 0, cur_ans = 0;
        int l = 0, r = 0;

        unordered_map<char, int> map;
        while (r < s.size()) {
            char c = s[r];
            map[c]++;
            cur_ans++;

            while (l < r && map[c] > 1) {
                map[s[l]]--;
                l++;
                cur_ans--;
            }

            ans = max(ans, cur_ans);
            r++;
        }

        return ans;
    }
};
```

## 2. 倒数第 K 个结点（5 分）

### 题目描述

实现一种算法，找出单向链表中倒数第 `k` 个结点，并返回该结点的值。

> 注意：本题相对原题稍作改动。

### 示例

- 输入：`1 -> 2 -> 3 -> 4 -> 5`，`k = 2`
- 输出：`4`
- 说明：给定的 `k` 保证有效。

### 参考实现

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    void fun(vector<int>&nums1, int m, vector<int>& nums2, int n)
    {
        int p1 = m-1, p2 = n-1, p = m+n-1;

        while (p2 >= 0)
        {
            if (p1 >= 0 && nums1[p1] > nums2[p2])
            {
                nums1[p] = nums1[p1];
                p--;
                p1--;
            }else
            {
                nums1[p] = nums2[p2];
                p--;
                p2--;
            }
        }
    }
};

int main()
{
    int m, n;
    cin >> m >> n;

    vector<int> nums1(m + n);
    vector<int> nums2(n);

    // nums1 输入 m + n 个数，后 n 个占位 0 也需要读入。
    for (int i = 0; i < m + n; i++)
    {
        cin >> nums1[i];
    }

    for (int i = 0; i < n; i++)
    {
        cin >> nums2[i];
    }

    Solution().fun(nums1, m, nums2, n);

    for (int i = 0; i < m + n; i++)
    {
        if (i > 0)
        {
            cout << ' ';
        }
        cout << nums1[i];
    }
    cout << '\n';

    return 0;
}

```

## 3. 合并有序数组（5 分）

### 题目描述

给你两个按**非递减顺序**排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你将 `nums2` 合并到 `nums1` 中，使合并后的数组同样按**非递减顺序**排列。

注意：最终，合并后数组不应由函数返回，而是存储在数组 `nums1` 中。为应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示待合并元素，后 `n` 个元素为 `0`，应忽略；`nums2` 的长度为 `n`。

### 示例 1

- 输入：`nums1 = [1,2,3,0,0,0]`，`m = 3`，`nums2 = [2,5,6]`，`n = 3`
- 输出：`[1,2,2,3,5,6]`
- 解释：需要合并 `[1,2,3]` 和 `[2,5,6]`。

### 参考实现

```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int p1 = m - 1, p2 = n - 1, p = m + n - 1;
        while (p2 >= 0)
        {
            if (p1 >=0 && nums1[p1] > nums2[p2])
            {
                nums1[p] = nums1[p1];
                p--;
                p1--;
            }else
            {
                nums1[p] = nums2[p2];
                p--;
                p2--;
            }
        }

    }
```

## 4. 搜索旋转排序数组

### 题目描述

整数数组 `nums` 按升序排列，数组中的值**互不相同**。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了向左旋转，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标从 `0` 开始计数）。例如，`[0,1,2,4,5,6,7]` 在下标 `3` 向左旋转后可能变为 `[4,5,6,7,0,1,2]`。

给你旋转后的数组 `nums` 和一个整数 `target`；如果 `nums` 中存在目标值 `target`，则返回其下标，否则返回 `-1`。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

### 示例 1

- 输入：`nums = [4,5,6,7,0,1,2]`，`target = 0`
- 输出：`4`

### 参考实现

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int l = 0, r = nums.size() - 1;
        int mid = 0;

        while (l <= r)
        {
            mid = (l + r) / 2;
            if (nums[mid] == target)
            {
                return mid;
            }
            
            if (nums[mid] >= nums[l])
            {
                if (nums[l] <= target && target < nums[mid])
                {
                    r = mid - 1;
                }else
                {
                    l = mid + 1;
                }
            }else
            {
                if (target > nums[mid] && target <= nums[r])
                {
                    l = mid + 1;
                }else
                {
                    r = mid -1;
                }
            }
        }
        
        return -1;
    }
};
```

## 5. 二叉树的中序遍历（1 分）

### 题目描述

给定一个二叉树的根结点 `root`，返回它的中序遍历。

![二叉树示例](img.png)

### 示例 1

- 输入：`root = [1,null,2,3]`
- 输出：`[1,3,2]`


### 参考实现

```cpp
class Solution
{
private:
    void dfs(TreeNode *root, vector<int>& nums)
    {
        if (root == nullptr) return;
        dfs(root->left, nums);
        nums.push_back(root->val);
        dfs(root->right, nums);
    }
public:
    vector<int> inorderTraversal(TreeNode* root)
    {

        vector<int> nums;

        if (!root) return nums;

        dfs(root, nums);

        return nums;

    }
};
```

## 6. 分割回文串（3 分）

### 题目描述

给定一个字符串 `s`，请将 `s` 分割成一些子串，使每个子串都是回文串，并返回 `s` 所有可能的分割方案。

回文串是正着读和反着读都一样的字符串。

### 示例 1

- 输入：`s = "google"`
- 输出：`[["g","o","o","g","l","e"],["g","oo","g","l","e"],["goog","l","e"]]`

### 参考实现

```cpp
class Solution {
public:
    bool is_palindrome(const string& s, int left, int right)
    {
        while (left < right)
        {
            if (s[left++] != s[right--])
            {
                return false;
            }
        }

        return true;
    }

    void dfs(const string& s, int n, int i, int start,
             vector<vector<string>>& ans, vector<string>& path)
    {
        if (i == n) { // s 分割完毕
            ans.emplace_back(path);
            return;
        }

        // 不分割
        if (i < n - 1) { // 最后一个字符必须作为最后一段的结尾
            dfs(s, n, i + 1, start, ans, path);
        }

        // 分割，得到子串 [start, i]
        if (is_palindrome(s, start, i)) {
            path.emplace_back(s.substr(start, i - start + 1));
            dfs(s, n, i + 1, i + 1, ans, path);
            path.pop_back(); // 恢复现场
        }
    }

    vector<vector<string>> partition(string s) {
        int n = s.size();
        vector<vector<string>> ans;
        vector<string> path;

        // 当前位于下标 i，讨论是否在 i 和 i+1 之间切一刀。
        dfs(s, n, 0, 0, ans, path);
        return ans;
    }
};
```
