## 1. 无重复字符的最长子串（10 次）

### 题目描述

给定一个字符串 `s`，请你找出其中不含有重复字符的最长子串的长度。

### 示例 1

- 输入：`s = "abcabcbb"`
- 输出：`3`
- 解释：因为无重复字符的最长子串是 `"abc"`，所以其长度为 `3`。注意，`"bca"` 和 `"cab"` 也是正确答案。

### 参考实现

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        if (s.empty()) {
            return 0;
        }

        int ans = 0, cur_ans = 0;
        int l = 0, r = 0;

        unordered_map<char, int> map;
        while (r < s.size()) {
            char c = s[r];
            map[c]++;
            cur_ans++;

            while (l < r && map[c] > 1) {
                map[s[l]]--;
                l++;
                cur_ans--;
            }

            ans = max(ans, cur_ans);
            r++;
        }

        return ans;
    }
};
```

## 2. 倒数第 K 个结点（5 次）

### 题目描述

实现一种算法，找出单向链表中倒数第 `k` 个结点，并返回该结点的值。

> 注意：本题相对原题稍作改动。

### 示例

- 输入：`1 -> 2 -> 3 -> 4 -> 5`，`k = 2`
- 输出：`4`
- 说明：给定的 `k` 保证有效。

### 参考实现

```cpp
class Solution {
public:
    int kthToLast(ListNode* head, int k) {

        ListNode* l = head;
        ListNode* r = head;

        for (int i = 0; i < k; i++)
        {
            r = r->next;
        }

        while (r != nullptr)
        {
            r = r->next;
            l = l->next;
        }

        return  l->val;
    }
};

```

## 3. 合并有序数组（5 次）

### 题目描述

给你两个按**非递减顺序**排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你将 `nums2` 合并到 `nums1` 中，使合并后的数组同样按**非递减顺序**排列。

注意：最终，合并后数组不应由函数返回，而是存储在数组 `nums1` 中。为应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示待合并元素，后 `n` 个元素为 `0`，应忽略；`nums2` 的长度为 `n`。

### 示例 1

- 输入：`nums1 = [1,2,3,0,0,0]`，`m = 3`，`nums2 = [2,5,6]`，`n = 3`
- 输出：`[1,2,2,3,5,6]`
- 解释：需要合并 `[1,2,3]` 和 `[2,5,6]`。

### 参考实现

```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int p1 = m - 1, p2 = n - 1, p = m + n - 1;
        while (p2 >= 0)
        {
            if (p1 >=0 && nums1[p1] > nums2[p2])
            {
                nums1[p] = nums1[p1];
                p--;
                p1--;
            }else
            {
                nums1[p] = nums2[p2];
                p--;
                p2--;
            }
        }

    }
};
```

## 4. 搜索旋转排序数组

### 题目描述

整数数组 `nums` 按升序排列，数组中的值**互不相同**。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了向左旋转，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标从 `0` 开始计数）。例如，`[0,1,2,4,5,6,7]` 在下标 `3` 向左旋转后可能变为 `[4,5,6,7,0,1,2]`。

给你旋转后的数组 `nums` 和一个整数 `target`；如果 `nums` 中存在目标值 `target`，则返回其下标，否则返回 `-1`。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

### 示例 1

- 输入：`nums = [4,5,6,7,0,1,2]`，`target = 0`
- 输出：`4`

### 参考实现

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int l = 0, r = nums.size() - 1;
        int mid = 0;

        while (l <= r)
        {
            mid = (l + r) / 2;
            if (nums[mid] == target)
            {
                return mid;
            }
            
            if (nums[mid] >= nums[l])
            {
                if (nums[l] <= target && target < nums[mid])
                {
                    r = mid - 1;
                }else
                {
                    l = mid + 1;
                }
            }else
            {
                if (target > nums[mid] && target <= nums[r])
                {
                    l = mid + 1;
                }else
                {
                    r = mid -1;
                }
            }
        }
        
        return -1;
    }
};
```

## 5. 二叉树的中序遍历（1 次）

### 题目描述

给定一个二叉树的根结点 `root`，返回它的中序遍历。

![二叉树示例](img.png)

### 示例 1

- 输入：`root = [1,null,2,3]`
- 输出：`[1,3,2]`


### 参考实现

```cpp
class Solution
{
private:
    void dfs(TreeNode *root, vector<int>& nums)
    {
        if (root == nullptr) return;
        dfs(root->left, nums);
        nums.push_back(root->val);
        dfs(root->right, nums);
    }
public:
    vector<int> inorderTraversal(TreeNode* root)
    {

        vector<int> nums;

        if (!root) return nums;

        dfs(root, nums);

        return nums;

    }
};
```

## 6. 分割回文串（3 次）

### 题目描述

给定一个字符串 `s`，请将 `s` 分割成一些子串，使每个子串都是回文串，并返回 `s` 所有可能的分割方案。

回文串是正着读和反着读都一样的字符串。

### 示例 1

- 输入：`s = "google"`
- 输出：`[["g","o","o","g","l","e"],["g","oo","g","l","e"],["goog","l","e"]]`

### 参考实现

```cpp
class Solution {
public:
    // 思路：回溯 DFS。每个字符间隙只有"切 / 不切"两种选择，
    // 枚举所有切法，闭合片段时用 is_palindrome 校验，非回文即剪枝。
    // 复杂度：最坏 O(n * 2^n)，空间 O(n)。

    // 双指针判断 s[left..right] 是否为回文
    bool is_palindrome(const string& s, int left, int right)
    {
        while (left < right)
        {
            if (s[left++] != s[right--])
            {
                return false;
            }
        }

        return true;
    }

    // 回溯。i：当前扫描到的位置；start：当前未闭合片段的起点（即片段为 s[start..i]）
    // path：已确定的片段（全是回文）；ans：收集所有完整方案
    void dfs(const string& s, int n, int i, int start,
             vector<vector<string>>& ans, vector<string>& path)
    {
        if (i == n) { // 走到末尾，得到一种完整分割
            ans.emplace_back(path);
            return;
        }

        // 分支一：不切，继续并入当前片段（最后一位不允许，否则最后一段不会被回文校验）
        if (i < n - 1) { // 最后一个字符必须作为最后一段的结尾
            dfs(s, n, i + 1, start, ans, path);
        }

        // 分支二：切，闭合片段 [start, i]，必须是回文才合法
        if (is_palindrome(s, start, i)) {
            path.emplace_back(s.substr(start, i - start + 1)); // 片段加入方案
            dfs(s, n, i + 1, i + 1, ans, path);                // 从 i+1 开始新片段
            path.pop_back(); // 回溯：撤销刚加入的片段，尝试其他分支
        }
    }

    vector<vector<string>> partition(string s) {
        int n = s.size();
        vector<vector<string>> ans;
        vector<string> path;

        // 从下标 0 开始，初始片段起点也是 0
        dfs(s, n, 0, 0, ans, path);
        return ans;
    }
};
```

## 7. 和可被 K 整除的子数组

### 题目描述

给定一个整数数组 `nums` 和一个整数 `k`，返回其中元素之和**可被 `k` 整除**的**非空**子数组的数目。

子数组是数组中**连续**的部分。

### 示例 1

- 输入：`nums = [4,5,0,-2,-3,1]`，`k = 5`
- 输出：`7`
- 解释：有 7 个子数组满足其元素之和可被 `k = 5` 整除：
  - `[4, 5, 0, -2, -3, 1]`
  - `[5]`
  - `[5, 0]`
  - `[5, 0, -2, -3]`
  - `[0]`
  - `[0, -2, -3]`
  - `[-2, -3]`

### 参考实现

```cpp
class Solution {
public:
    // 前缀和 + 同余定理：子数组和可被 k 整除 ⇔ 两端前缀和模 k 的余数相同
    int subarraysDivByK(vector<int>& nums, int k) {
        unordered_map<int, int> cnt; // 余数 -> 出现次数
        int ans = 0, s = 0;          // ans：结果；s：当前前缀和模 k 的余数
        for (int x : nums) {
            cnt[s]++;                          // 登记当前前缀（首轮即空前缀）
            s = (s + x % k + k) % k;           // 累加 x 后取模，+k 保证余数非负
            ans += cnt[s];                     // 余数相同的历史前缀数 = 新增合法子数组数
        }
        return ans;
    }
};
```

## 8. 最长连续序列

### 题目描述

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

### 示例 1

- 输入：`nums = [100,4,200,1,3,2]`
- 输出：`4`
- 解释：最长数字连续序列是 `[1, 2, 3, 4]`，它的长度为 `4`。

### 参考实现

```cpp
class Solution {
public:
    // 思路：哈希集合去重后，只从「连续序列的起点」（num-1 不存在）开始向后延伸，整体 O(n)
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> num_set; // 所有数存入集合，供 O(1) 查找

        for (const auto& num : nums) {
            num_set.insert(num);
        }

        int ans = 0;

        for (const auto& num : num_set) {
            // num-1 不存在 ⇒ num 是某段连续序列的起点，从它开始数
            if (!num_set.count(num - 1)) {
                int currentNum = num;
                int curAns = 1;

                // 向后延伸：num+1、num+2 ... 直到断开
                while (num_set.count(currentNum + 1)) {
                    currentNum++;
                    curAns++;
                }

                ans = max(ans, curAns);
            }
        }

        return ans;
    }
};
```

## 9. 三数之和

### 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 `0` 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

### 示例 1

- 输入：`nums = [-1,0,1,2,-1,-4]`
- 输出：`[[-1,-1,2],[-1,0,1]]`
- 解释：
  - `nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0`
  - `nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0`
  - `nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0`
  - 不同的三元组是 `[-1,0,1]` 和 `[-1,-1,2]`，输出的顺序和三元组的顺序并不重要。

### 参考实现

```cpp
class Solution {
public:
    // 思路：排序 + 固定一个数 + 双指针收缩，跳过重复元素去重
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end()); // 排序后双指针才有单调性

        int n = nums.size();

        vector<vector<int>> ans;

        for (int i = 0; i < n; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue; // 跳过重复的固定数

            int l = i + 1, r = n - 1; // 双指针在 i 右侧找两数之和 = -nums[i]
            while (l < r) {
                int s = nums[i] + nums[l] + nums[r];
                if (s < 0) l++;       // 和太小，左指针右移
                else if (s > 0) r--;  // 和太大，右指针左移
                else {
                    ans.push_back({nums[i], nums[l], nums[r]});
                    while (l < r && nums[l] == nums[l + 1]) l++; // 跳过重复
                    while (l < r && nums[r] == nums[r - 1]) r--; // 跳过重复
                    l++; r--;
                }
            }
        }

        return ans;
    }
};
```

## 10. 和为 K 的子数组

### 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的子数组的个数。

子数组是数组中元素的连续非空序列。

### 示例 1

- 输入：`nums = [1,1,1]`，`k = 2`
- 输出：`2`

### 参考实现

```cpp
class Solution {
public:
    // 思路：前缀和 + 哈希表。子数组和 = S[i] - S[j] = k ⇔ S[j] = S[i] - k
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> map; // 前缀和 -> 出现次数
        map[0] = 1;                  // 空前缀和为 0，出现 1 次

        int preSum = 0; // 当前前缀和
        int count = 0;  // 结果

        for (auto x : nums) {
            preSum += x;
            // 之前存在前缀和 = preSum - k，则它们到当前位置的区间和为 k
            if (map.find(preSum - k) != map.end()) {
                count += map[preSum - k];
            }

            map[preSum]++; // 登记当前前缀和
        }

        return count;
    }
};
```

## 11. 数组中的第 K 个最大元素

### 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

### 示例 1

- 输入：`nums = [3,2,1,5,6,4]`，`k = 2`
- 输出：`5`

### 参考实现

```cpp
class Solution {
public:
    // 思路：快速选择（快排分区思想）。按 pivot 分成 大/等/小 三组，
    // 根据 k 落在哪一组只递归一边，平均 O(n)
    int quickSelect(vector<int>& nums, int k) {
        int pivot = nums[rand() % nums.size()]; // 随机选基准

        vector<int> big, equal, small; // 大于 / 等于 / 小于 pivot
        for (int num : nums) {
            if (num > pivot) big.push_back(num);
            else if (num < pivot) small.push_back(num);
            else equal.push_back(num);
        }

        // 第 k 大在 big 中，继续在 big 里找
        if (k <= big.size()) return quickSelect(big, k);
        // 第 k 大在 small 中：big + equal 不足 k 个，去掉它们后重新排名
        if (nums.size() - small.size() < k)
            return quickSelect(small, k - nums.size() + small.size());
        // 第 k 大落在 equal 中，即 pivot
        return pivot;
    }

    int findKthLargest(vector<int>& nums, int k) {
        return quickSelect(nums, k);
    }
};
```

## 12. 相交链表

### 题目描述

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。

![相交链表示例](img_1.png)

### 示例 1

- 输入：`intersectVal = 8`，`listA = [4,1,8,4,5]`，`listB = [5,6,1,8,4,5]`，`skipA = 2`，`skipB = 3`
- 输出：`Intersected at '8'`
- 解释：相交节点的值为 `8`；如果两个链表不存在相交节点，则返回 `null`。

### 参考实现

```cpp
class Solution {
public:
    // 思路：换路双指针。A 走完自己换到 B 链头，B 走完自己换到 A 链头，
    // 两者总步数相同（a+b+c），必然同时到达交点；无交点则同时走到 nullptr
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode* A = headA, * B = headB; // 两个指针分别从两条链头部出发
        while (A != B) {                   // 比较的是节点地址，同一节点才算相交
            A = A != nullptr ? A->next : headB; // 走到尽头就换到另一条链的头部
            B = B != nullptr ? B->next : headA;
        }
        return A; // 相遇节点即交点；无交点时 A == B == nullptr
    }
};
```

## 13. 反转链表

### 题目描述

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

![反转链表示例](img_2.png)

### 示例 1

- 输入：`head = [1,2,3,4,5]`
- 输出：`[5,4,3,2,1]`

### 参考实现

```cpp
class Solution {
public:
    // 思路：迭代 + 三指针。遍历时把每个节点的 next 指向前一个节点 pre，就地反转
    ListNode* reverseList(ListNode* head) {
        ListNode* cur = head, *pre = nullptr; // cur 当前节点；pre 已反转部分的新头
        while (cur != nullptr) {
            ListNode* temp = cur->next; // 先保存下一个节点，防止断链
            cur->next = pre;            // 当前节点指向前一个节点（反转方向）
            pre = cur;                  // pre 前移
            cur = temp;                 // cur 前移
        }
        return pre; // 循环结束 pre 指向原链表尾节点，即反转后的新头
    }
};
```

## 14. LRU 缓存

### 题目描述

请你设计并实现一个满足 **LRU（最近最少使用）缓存**约束的数据结构。

实现 `LRUCache` 类：

- `LRUCache(int capacity)`：以正整数作为容量 `capacity` 初始化 LRU 缓存
- `int get(int key)`：如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1`
- `void put(int key, int value)`：如果关键字 `key` 已经存在，则变更其数据值 `value`；如果不存在，则向缓存中插入该组 `key-value`。如果插入操作导致关键字数量超过 `capacity`，则应该**逐出最久未使用的关键字**

函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

### 示例 1

- 输入：`["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]`、`[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]`
- 输出：`[null, null, null, 1, null, -1, null, -1, 3, 4]`
- 解释：
  - `LRUCache lRUCache = new LRUCache(2);` —— 容量为 `2`
  - `lRUCache.put(1, 1);` —— 缓存是 `{1=1}`
  - `lRUCache.put(2, 2);` —— 缓存是 `{1=1, 2=2}`
  - `lRUCache.get(1);` —— 返回 `1`
  - `lRUCache.put(3, 3);` —— 该操作会使得关键字 `2` 作废，缓存是 `{1=1, 3=3}`
  - `lRUCache.get(2);` —— 返回 `-1`（未找到）
  - `lRUCache.put(4, 4);` —— 该操作会使得关键字 `1` 作废，缓存是 `{4=4, 3=3}`
  - `lRUCache.get(1);` —— 返回 `-1`（未找到）
  - `lRUCache.get(3);` —— 返回 `3`
  - `lRUCache.get(4);` —— 返回 `4`

### 参考实现

```cpp
#include <unordered_map>
#include <list>
#include <iostream>
#include <string>
#include <vector>
#include <cctype>
using namespace std; // 本地编译所需；LeetCode 在线提交时可省略头文件与 using

class LRUCache {
private:
    // cache：key -> 双向链表中对应节点的迭代器，实现 O(1) 定位
    unordered_map<int, list<pair<int,int>>::iterator> cache;
    // lrulist：双向链表，头部 = 最近使用，尾部 = 最久未使用
    list<pair<int,int>> lrulist;
    int capacity; // 容量上限
public:
    LRUCache(int _capacity) {
        capacity = _capacity;
    }

    // get：命中则把该节点移到链表头部（标记为最近使用），返回其值；未命中返回 -1
    int get(int key){
        if(cache.find(key) != cache.end()) {
            lrulist.splice(lrulist.begin(), lrulist, cache[key]); // O(1) 移到头部
            return cache[key]->second;
        } else{
            return -1;
        }
    }

    // put：key 已存在 → 移到头部并更新值；
    //      key 不存在 → 插入头部；若超出容量，淘汰链表尾部（最久未使用）
    void put(int key, int val){
        if(cache.find(key) != cache.end()){
            lrulist.splice(lrulist.begin(), lrulist, cache[key]); // 移到头部
            cache[key]->second = val;                              // 更新值
        } else{
            lrulist.push_front({key, val}); // 新节点插入链表头部
            cache[key] = lrulist.begin();   // 记录迭代器，供 O(1) 定位

            if(lrulist.size() > capacity){  // 超出容量，淘汰最久未使用的尾部节点
                int lrukey = lrulist.back().first; // 取尾部节点对应的 key
                lrulist.pop_back();                // 从链表移除
                cache.erase(lrukey);               // 从哈希表移除
            }
        }
    }
};

int main()
{
    // ===== 写死的测试数据（参考题目示例 1，手动逐条调用）=====
    // 输入：["LRUCache","put","put","get","put","get","put","get","get","get"]
    //       [[2],[1,1],[2,2],[1],[3,3],[2],[4,4],[1],[3],[4]]
    // 期望输出：[null, null, null, 1, null, -1, null, -1, 3, 4]

    LRUCache lRUCache(2);

    lRUCache.put(1, 1);              // -> null
    lRUCache.put(2, 2);              // -> null
    cout << lRUCache.get(1) << endl; // -> 1
    lRUCache.put(3, 3);              // -> null
    cout << lRUCache.get(2) << endl; // -> -1
    lRUCache.put(4, 4);              // -> null
    cout << lRUCache.get(1) << endl; // -> -1
    cout << lRUCache.get(3) << endl; // -> 3
    cout << lRUCache.get(4) << endl; // -> 4

    return 0;
}
```
